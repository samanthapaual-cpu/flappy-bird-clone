# Flappy Bird Clone

A learning-based Flappy Bird clone created as part of my journey in learning JavaScript, Node.js, Express, PostgreSQL, and Git/GitHub.

This project started as a clone based on an existing Flappy Bird tutorial. I gradually modified and extended it while learning more about JavaScript and backend development.
